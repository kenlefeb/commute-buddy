# Review Session Contract

## Steps
1. Capture: Collect new items, thoughts, or tasks
2. Clarify: Define next actions and outcomes
3. Organize: Sort items into lists or categories
4. Reflect: Review priorities and commitments
5. Engage: Decide what to do next

## Acceptance Criteria
- Each step must be completed or explicitly skipped
- Session summary generated at end
- User can pause, resume, or end session at any time
