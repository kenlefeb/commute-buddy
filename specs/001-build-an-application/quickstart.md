# Quickstart Guide: Generative AI Daily Review Companion

## Prerequisites
- .NET 8 SDK
- .NET MAUI workload installed
- API key for generative AI (e.g., OpenAI)
- (Optional) Cloud storage credentials (AWS/Azure)

## Setup
1. Clone the repository
2. Install dependencies
3. Configure API keys and storage options
4. Build and run the MAUI app on your platform

## Running Tests
- Run `dotnet test` in the tests/ directory
- Contract, integration, and unit tests are included

## Usage
- Launch the app on your device
- Start a Daily Review session
- Interact hands-free using voice
- Review session summary and notes are stored locally or in the cloud

## Troubleshooting
- Ensure microphone permissions are enabled
- Check API key validity for generative AI
- Review logs for errors in the app or backend
