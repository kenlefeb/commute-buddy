# Quickstart: .NET MAUI Generative AI Daily Review Companion

## Prerequisites
- .NET 8 SDK or later
- Visual Studio 2022+ (Windows/macOS) with MAUI workload
- Optional: AWS/Azure account for cloud AI APIs

## Setup
1. Clone the repository
2. Open solution in Visual Studio
3. Restore NuGet packages
4. Build and run on your platform (Windows, macOS, iOS, Android)

## Key Steps
- Implement data model from `data-model.md`
- Integrate voice interaction using platform APIs
- Connect to generative AI via REST API (OpenAI, AWS, Azure, etc.)
- Use contracts in `contracts/` for API, voice, and review session logic

## Hosting
- App runs locally on device
- Backend (if needed) can be hosted on AWS, Azure, or locally
